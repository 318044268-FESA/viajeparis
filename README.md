# TravelAgent Pro

Plataforma de comparación y venta de paquetes de viaje, hecha con React + Vite + Bootstrap.

## Demo

👉 https://318044268-FESA.github.io/viajeparis/

## Funcionalidades

- Login con selección de rol (agente / recopilador)
- Panel del agente con accesos rápidos y stats
- Comparación de vuelos con filtros por aerolínea y tipo
- Comparación de hospedajes con orden por precio, calificación y distancia
- Resumen del paquete con subtotal, impuestos (16%) y total
- Módulo de cobro con método, modalidad y referencia
- Carga de vuelos y hospedajes (rol recopilador)
- Perfil de usuario editable
